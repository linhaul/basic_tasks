# Unity & C# Learning Sandbox

Песочница для изучения Unity и C# с нуля. Цель — стать инди-разработчиком.

## Стек
- Unity 6.3 LTS (6000.3.14f1)
- C# / .NET
- 2D-проект, Active Input Handling: Both

## Структура
Все задачи лежат в `Assets/_Sandbox/` и изолированы в свои namespace'ы (`Sandbox.TaskXX`).
